Base URL: http://product-service/api/v1

Product APIs
| Method   | Endpoint                 | Description                                         |
| -------- | ------------------------ | --------------------------------------------------- |
| `POST`   | `/products/`             | Create a new product                                |
| `GET`    | `/products/`             | Get list of all products (with filters, pagination) |
| `GET`    | `/products/{product_id}` | Get a single product by ID                          |
| `PUT`    | `/products/{product_id}` | Fully update a product                              |
| `PATCH`  | `/products/{product_id}` | Partially update a product                          |
| `DELETE` | `/products/{product_id}` | Delete a product                                    |

✅ **Filters** (query params for GET `/products/`):
/products?category_id=abc123&is_active=true&min_price=10&max_price=50&limit=20&page=1

Product Image APIs
| Method   | Endpoint                                   | Description                  |
| -------- | ------------------------------------------ | ---------------------------- |
| `POST`   | `/products/{product_id}/images/`           | Add a new image to a product |
| `GET`    | `/products/{product_id}/images/`           | List images of a product     |
| `DELETE` | `/products/{product_id}/images/{image_id}` | Delete a product image       |


Category APIs
| Method   | Endpoint                    | Description                                        |
| -------- | --------------------------- | -------------------------------------------------- |
| `POST`   | `/categories/`              | Create a new category                              |
| `GET`    | `/categories/`              | Get list of categories (with optional `parent_id`) |
| `GET`    | `/categories/{category_id}` | Get a category by ID                               |
| `PUT`    | `/categories/{category_id}` | Fully update a category                            |
| `PATCH`  | `/categories/{category_id}` | Partially update a category                        |
| `DELETE` | `/categories/{category_id}` | Delete a category                                  |


Example API Usage

* Get all active products under a specific category:
GET /api/v1/products?category_id=123&is_active=true

* Upload product image:
POST /api/v1/products/123/images
Body: {
  "url": "https://cdn.mystore.com/product123-main.jpg"
}
